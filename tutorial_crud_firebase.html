Tutorial: CRUD com Python e Firebase

1. Introdução

Este tutorial ensina como criar um sistema CRUD (Create, Read, Update, Delete) em Python utilizando o Firebase como banco de dados. O exemplo será baseado em uma oficina mecânica, com tabelas para mecânicos, especialidades e ordens de serviço.

2. Configuração do Firebase

  1. Acesse o Firebase Console e crie um novo projeto.
  2. Vá em Configurações do projeto > Contas de serviço.
  3. Clique em Gerar nova chave privada e baixe o arquivo JSON.
  4. Salve esse arquivo no diretório do seu projeto Python.

3. Instalação das dependências

Instale o SDK do Firebase Admin com o seguinte comando:

pip install firebase-admin

4. Inicialização do Firebase no Python

import firebase_admin
from firebase_admin import credentials, firestore

cred = credentials.Certificate('caminho/para/seu/arquivo-chave.json')
firebase_admin.initialize_app(cred)
db = firestore.client()

5. Estrutura das coleções

  • Especialidade: id_especialidade, nome
  • Mecanico: id_mecanico, nome, telefone
  • OS: id_os, data, descricao, status, id_mecanico
  • MecanicoEspecialidade: id_mecanico, id_especialidade

6. Funções CRUD

6.1 Criar Especialidade

def criar_especialidade(nome):
    doc_ref = db.collection('Especialidade').document()
    doc_ref.set({'nome': nome})

6.2 Listar Especialidades

def listar_especialidades():
    docs = db.collection('Especialidade').stream()
    for doc in docs:
        print(doc.id, doc.to_dict())

6.3 Atualizar Especialidade

def atualizar_especialidade(id, novo_nome):
    db.collection('Especialidade').document(id).update({'nome': novo_nome})

6.4 Excluir Especialidade

def excluir_especialidade(id):
    db.collection('Especialidade').document(id).delete()

As demais entidades seguem a mesma lógica: Mecanico, OS e MecanicoEspecialidade.

7. Exemplos de uso

# Criar uma especialidade
criar_especialidade("Suspensão")

# Listar todas as especialidades
listar_especialidades()

# Atualizar uma especialidade
atualizar_especialidade("id_do_documento", "Freios")

# Excluir uma especialidade
excluir_especialidade("id_do_documento")

8. Conclusão

Com esse tutorial, você aprendeu a configurar o Firebase e implementar um CRUD completo em Python para gerenciar dados de uma oficina mecânica. Esse modelo pode ser expandido para incluir autenticação, interface gráfica e muito mais.
