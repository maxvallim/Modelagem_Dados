SQL para Consultas e Manipulação de Dados

Guia Prático para Atividades de Modelagem de Dados utilizando MySQL

Introdução

Após a criação das tabelas no banco de dados, o próximo passo consiste em trabalhar com os dados armazenados. Para isso utilizamos a linguagem SQL (Structured Query Language).

Este tutorial apresenta os principais comandos utilizados para:

  • Inserir dados;
  • Consultar informações;
  • Atualizar registros;
  • Excluir registros;
  • Aplicar filtros e pesquisas;
  • Criar relatórios e estatísticas;
  • Relacionar informações entre tabelas.

1. INSERT INTO

O que é?

O comando INSERT INTO é utilizado para inserir novos registros em uma tabela.

Quando utilizar?

Sempre que houver necessidade de cadastrar novas informações no sistema.

Exemplo

INSERT INTO clientes
(nome, cidade)
VALUES
('João Silva', 'São Paulo');
Resultado: Um novo cliente será inserido na tabela.

Inserindo vários registros

INSERT INTO clientes
(nome, cidade)
VALUES
('Maria Souza', 'Campinas'),
('Pedro Santos', 'Aguaí'),
('Ana Lima', 'Poços de Caldas');
Resultado: Três novos clientes serão cadastrados em uma única operação.

2. SELECT

O que é?

O comando SELECT é utilizado para consultar informações armazenadas no banco.

Consultando todos os campos

SELECT *
FROM clientes;
Resultado: Todos os registros e colunas da tabela clientes.

Consultando campos específicos

SELECT nome, cidade
FROM clientes;
Resultado: Apenas os campos nome e cidade serão exibidos.

3. WHERE

O que é?

A cláusula WHERE permite filtrar os registros retornados pela consulta.

Filtro de igualdade

SELECT *
FROM clientes
WHERE cidade = 'Aguaí';
Resultado: Apenas clientes da cidade de Aguaí.

Filtro de diferença

SELECT *
FROM clientes
WHERE cidade <> 'Aguaí';
Resultado: Clientes de todas as cidades, exceto Aguaí.

Valor maior que

SELECT *
FROM produtos
WHERE preco > 100;
Resultado: Produtos com preço superior a R$ 100,00.

Valor menor que

SELECT *
FROM produtos
WHERE preco < 100;
Resultado: Produtos com preço inferior a R$ 100,00.

4. LIKE

O que é?

LIKE é utilizado para pesquisas parciais em campos textuais.

Nomes iniciados pela letra A

SELECT *
FROM clientes
WHERE nome LIKE 'A%';
Resultado: Ana, Amanda, André...

Nomes terminados por Silva

SELECT *
FROM clientes
WHERE nome LIKE '%Silva';
Resultado: João Silva, Carlos Silva...

Nomes contendo Souza

SELECT *
FROM clientes
WHERE nome LIKE '%Souza%';
Resultado: Maria Souza, José Souza Lima...

5. BETWEEN

Utilizado para pesquisar dados dentro de um intervalo de valores. 

SELECT *
FROM produtos
WHERE preco BETWEEN 100 AND 500;
Resultado: Produtos com preços entre R$ 100,00 e R$ 500,00.

6. IN

Permite pesquisar diversos valores simultaneamente. 

SELECT *
FROM clientes
WHERE cidade IN
('Aguaí','Campinas','São Paulo');
Resultado: Clientes localizados em qualquer uma das cidades informadas.

7. AND e OR

AND

Retorna os registros que atendem todas as condições. 

SELECT *
FROM produtos
WHERE preco > 100
AND estoque > 0;
Resultado: Produtos acima de R$ 100,00 e disponíveis em estoque.

OR

Retorna os registros que atendem pelo menos uma das condições. 

SELECT *
FROM clientes
WHERE cidade = 'Aguaí'
OR cidade = 'São João da Boa Vista';
Resultado: Clientes de Aguaí ou São João da Boa Vista.

8. ORDER BY

Responsável por ordenar os resultados retornados pela consulta.

Ordem crescente

SELECT *
FROM clientes
ORDER BY nome;
Resultado: Registros ordenados de A até Z.

Ordem decrescente

SELECT *
FROM produtos
ORDER BY preco DESC;
Resultado: Registros do maior valor para o menor.

9. UPDATE

Utilizado para alterar registros já existentes. 

UPDATE clientes
SET cidade = 'Campinas'
WHERE id = 1;
Resultado: A cidade do cliente com ID 1 será atualizada.

Atualizando vários campos

UPDATE produtos
SET
preco = 250,
estoque = 100
WHERE id = 5;
Resultado: Preço e estoque serão alterados simultaneamente.

10. DELETE

Utilizado para remover registros. 

DELETE FROM clientes
WHERE id = 10;
Resultado: O cliente com ID 10 será removido.

11. COUNT()

Conta a quantidade de registros existentes. 

SELECT COUNT(*) AS total
FROM clientes;
Resultado: Total de clientes cadastrados.

12. SUM()

Realiza a soma de valores numéricos. 

SELECT SUM(valor)
FROM vendas;
Resultado: Valor total vendido.

13. AVG()

Calcula a média de valores. 

SELECT AVG(valor)
FROM vendas;
Resultado: Média das vendas realizadas.

14. MAX() e MIN()

Maior valor

SELECT MAX(valor)
FROM vendas;
Resultado: Maior valor registrado.

Menor valor

SELECT MIN(valor)
FROM vendas;
Resultado: Menor valor registrado.

15. GROUP BY

Permite agrupar registros para produzir relatórios estatísticos. 

SELECT
cidade,
COUNT(*) AS quantidade
FROM clientes
GROUP BY cidade;
Resultado: Quantidade de clientes por cidade.

16. INNER JOIN

Relaciona informações que estão armazenadas em tabelas diferentes. 

SELECT
c.nome,
p.id AS pedido
FROM clientes c
INNER JOIN pedidos p
ON c.id = p.cliente_id;
Resultado: Exibe os clientes juntamente com seus respectivos pedidos.

17. JOIN com Três Tabelas

Também é possível relacionar mais de duas tabelas em uma mesma consulta. 

SELECT
c.nome,
p.id,
pr.descricao
FROM pedidos p
INNER JOIN clientes c
ON c.id = p.cliente_id
INNER JOIN produtos pr
ON pr.id = p.produto_id;
Resultado: Exibe cliente, pedido e produto em uma única consulta.

Exercícios para Praticar

  1. Liste todos os registros da entidade principal.
  2. Faça uma consulta utilizando WHERE.
  3. Utilize LIKE para pesquisar textos.
  4. Ordene registros com ORDER BY.
  5. Conte registros utilizando COUNT().
  6. Some valores utilizando SUM().
  7. Calcule médias utilizando AVG().
  8. Utilize GROUP BY para gerar estatísticas.
  9. Crie pelo menos um INNER JOIN.
  10. Atualize um registro com UPDATE.
  11. Exclua um registro utilizando DELETE.

Objetivo: Ao concluir estes exercícios, o aluno terá utilizado os principais comandos necessários para manipular dados e construir consultas em bancos de dados relacionais utilizando MySQL.
